# Xuman 的博客（xuman.lovie.me）

纯静态站点，无需构建：`index.html` 首页、`posts/` 文章页、`style.css` 样式、`CNAME` 自定义域名（GitHub Pages 用）。

## 部署选项（任选其一，均为免费）
- **GitHub Pages**：把本目录推到 GitHub 仓库 → Settings → Pages 选分支发布 → 在 LovieMe 控制台给 xuman 子域名加 CNAME 记录指向 `<用户名>.github.io`。
- **Cloudflare Pages / Vercel / Netlify**：导入仓库或直接拖拽上传本目录 → 在平台里绑定自定义域名 → 按平台给出的目标在 LovieMe 控制台加 CNAME 记录。

## 写新文章
复制 `posts/hello-world.html` 改标题和正文，再在 `index.html` 的文章列表里加一张卡片即可。或者把文章内容发给 M 代为排版发布。
